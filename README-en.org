#+title: org-quote-link
#+author: Riko
#+options: toc:nil num:nil

[[file:README.org][中文]] · English

Put point on an Org link and run =org-quote-link= and the link line is replaced by
a quote block whose header carries the link and whose body is an escaped
snapshot of the target.

#+begin_src org
  [[file:~/notes/emacs.org::*Org links]]
#+end_src

After running the command:

#+begin_src org
  #+HEADER: :transclude [[file:~/notes/emacs.org::*Org links]]
  ,#+begin_quote
  ,* Org links
  The body of the heading……

  ,** A subheading
  Its body.
  ,#+end_quote
#+end_src

* Installation

Requirements: Emacs 27.1 and Org 9.3. The package depends on Org only; it
does not need, load, or call org-transclusion or org-transclusion-blocks.

** TomoElpa (recommended)

[[https://blog.prayhand13013.top/tomoelpa/][TomoElpa]] is the recommended way to install
org-quote-link. It provides both snapshots built from the latest commit and
versioned releases. The archive paths have no browsable directory index; see
the TomoElpa page for the package list — the URLs below are what
=package.el= reads. Add the snapshots archive to =package-archives= and
refresh the package index, then let =use-package= install and configure the
package (Emacs 29 and later bundle =use-package= natively; Emacs 27–28 need
it from GNU ELPA first):

#+begin_src emacs-lisp
  (require 'package)
  (add-to-list 'package-archives
               '("tomoelpa-snapshots" .
                 "https://blog.prayhand13013.top/tomoelpa/snapshots/") t)
  (package-initialize)
  (package-refresh-contents)  ; once, or after the archive is updated

  (require 'use-package)

  (use-package org-quote-link
    :ensure t
    :pin tomoelpa-snapshots
    :bind (("C-c q" . org-quote-link)
           :map org-mode-map
           ("C-c Q" . org-quote-link-refresh)))
#+end_src

To use versioned releases instead of snapshots, switch the archive to
=tomoelpa-releases= and update =:pin= accordingly:

#+begin_src emacs-lisp
  (add-to-list 'package-archives
               '("tomoelpa-releases" .
                 "https://blog.prayhand13013.top/tomoelpa/releases/") t)
  (package-refresh-contents)

  (use-package org-quote-link
    :ensure t
    :pin tomoelpa-releases
    :bind (("C-c q" . org-quote-link)
           :map org-mode-map
           ("C-c Q" . org-quote-link-refresh)))
#+end_src

If you do not use =use-package= you can run
=M-x package-install RET org-quote-link RET= once.

** The =:vc= keyword of use-package

On Emacs 30.1 and later, the =:vc= keyword of =use-package= can install the
package straight from GitHub, without a package archive:

#+begin_src emacs-lisp
  (use-package org-quote-link
    :vc (:url "https://github.com/TomoeMami/org-quote-link" :rev :newest)
    :bind (("C-c q" . org-quote-link)
           :map org-mode-map
           ("C-c Q" . org-quote-link-refresh)))
#+end_src

=:rev :newest= checks out the latest commit. If =:rev= is omitted, =:vc=
tries the latest release; this repository has no release tags, so keep
=:rev :newest= and make sure =git= and network access are available. To
update later, run =M-x package-vc-upgrade RET org-quote-link RET= and it
will update the package.

On older Emacs versions use TomoElpa or =straight.el= instead.

** Manual installation

Clone the repository and add the directory to =load-path= first:

#+begin_src emacs-lisp
  (add-to-list 'load-path "/path/to/org-quote-link")
  (require 'org-quote-link)
#+end_src

Then bind the commands as needed:

#+begin_src emacs-lisp
  (define-key org-mode-map (kbd "C-c q") #'org-quote-link)
  (define-key org-mode-map (kbd "C-c Q") #'org-quote-link-refresh)
#+end_src

* Usage

** Recommended entry point

Bind =org-quote-link= and let it pick the action from the position of point:

| Point position                                        | Action                        |
|-------------------------------------------------------+-------------------------------|
| Inside a block with a =#+HEADER: :transclude [[LINK]]= line | Refresh that block            |
| On a single-line Org link                             | Convert it into a quote block |
| Anywhere else                                         | Signal an error, leave buffer |

Blocks are checked before links, so a link inside such a block triggers a
refresh. The two explicit commands below are still available when you want to
force a specific action.

** Convert a link (explicit command)

With point on the link, run =org-quote-link-at-point= and follow these rules:

- The link must be alone on its line (leading whitespace is fine); an inline
  link signals an error and leaves the buffer unchanged.
- Only link types produced by =org-store-link= are accepted: =file:= links
  (headings, CUSTOM_ID, targets, named elements, text searches, whole files),
  =id:= links, and third-party types that register a =:store= function (for
  example denote).
- By default a heading is quoted together with its headline line; set
  =org-quote-link-include-headline= to nil to quote only its contents. Org
  sources are comma-escaped so that lines starting with =*= or =#+= cannot
  break the quote block.

See the technical details linked below for the full link-type table.

** Refresh (explicit command)

A quote block is a snapshot. Put point inside the block and run
=org-quote-link-refresh= to fetch the content again; point may be on the
header, begin, body, or end line. The command depends on Org only and uses
the =#+HEADER: :transclude [[LINK]]= line to find the link.

Running =org-quote-link= inside the block does the same thing.

** Auto-refresh mode

Enable the global minor mode =org-quote-link-auto-refresh-mode= and every
time you open an Org file, the package checks whether the buffer contains
blocks with a =#+HEADER: :transclude [[LINK]]= line. If it does, the contents
of all such blocks are fetched again:

#+begin_src emacs-lisp
  (org-quote-link-auto-refresh-mode 1)
#+end_src

With =use-package=:

#+begin_src emacs-lisp
  (use-package org-quote-link
    :config
    (org-quote-link-auto-refresh-mode 1))
#+end_src

Details:

- Only Org buffers are considered, and only blocks with a
  =#+HEADER: :transclude [[LINK]]= line are refreshed; other quote blocks are
  left alone.
- The refresh runs when a file is opened. Changes made to the source file
  afterwards are not watched; use =org-quote-link-refresh= for one block or
  =org-quote-link-refresh-buffer= for the whole buffer when you need an
  immediate refresh.
- Refresh is synchronous. If a block is already up to date it is not
  rewritten, so visiting an up-to-date file leaves the buffer unmodified;
  when content does change, the buffer becomes modified and you decide
  whether to save it.
- If one block cannot be refreshed (for example its target file is missing),
  that block is left as it is while the other blocks are still refreshed, and
  a summary is echoed.
- Files opened only to fetch a snapshot are not auto-refreshed themselves, so
  the refresh does not nest.

You can also refresh every block in the current buffer manually with
=M-x org-quote-link-refresh-buffer=.

** Common settings

| Variable                                 | Default | Purpose                        |
|------------------------------------------+---------+--------------------------------|
| =org-quote-link-block-type=              | "quote" | Block type to generate         |
| =org-quote-link-include-headline=        | t       | Include the heading line       |
| =org-quote-link-escape-non-org-syntax=   | nil     | Escape non-Org content as well |
| =org-quote-link-link-handlers=           | denote  | Extend custom link types       |

See the technical details for the remaining variables and the extension
interface.

* Differences from org-transclusion-blocks

Both use a =#+HEADER: :transclude [[LINK]]= line plus a quote block, but they
serve different purposes. org-quote-link is a zero-dependency helper that only
turns the link at point into a quote block and stores a snapshot.
org-transclusion-blocks is a component-based transclusion framework that
fetches, refreshes, adjusts ranges, and adds overlays under its own header
syntax.

| Aspect            | org-quote-link                            | org-transclusion-blocks                         |
|-------------------+-------------------------------------------+-------------------------------------------------|
| Dependencies      | Org only (Emacs 27.1, Org 9.3)            | Emacs 29.1, Org 9.7, org-transclusion 1.4       |
| Purpose           | One command: link to quote-block snapshot | Framework: write headers/blocks, then fetch     |
| Input             | An existing org-link at point             | Existing headers and blocks                     |
| Link types        | Types produced by org-store-link          | Everything the org-transclusion fetchers handle |
| Content granularity | Heading, element, whole file            | Also lines, thing-at-point, only-contents, etc. |
| Block types       | quote (configurable to example or verse)  | src, quote, example, special, …; src uses Babel |
| Refresh           | Built-in single-block, whole-buffer, and auto refresh | org-transclusion-blocks-add or its menu         |
| Escaping          | Org sources escaped, non-Org verbatim     | Controlled by org-transclusion-blocks options   |
| Metadata          | None; plain text output                   | Text properties, overlays, etc.                 |
| Self-reference    | Refuses heading/element/whole-file nesting | Has its own checks                             |

How to choose:

- Use org-quote-link if you want a one-command conversion, zero dependencies,
  and a built-in refresh command.
- Use org-transclusion-blocks if you need lines, thing-at-point, component
  types, menus, or overlays.
- They can coexist: the format produced by org-quote-link follows the same
  header convention, so the blocks add command usually understands it. That
  is optional interoperability, not a dependency of org-quote-link; see the
  technical details for the caveats.

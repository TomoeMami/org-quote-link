#+title: org-quote-link
#+author: Riko
#+options: toc:nil num:nil

把光标放在一个 Org 链接上，执行 =org-quote-link-at-point=，链接所在行就会变成
一个带 header 链接的 quote-block，内容是链接所指对象的转义快照：

#+begin_src org
  [[file:~/notes/emacs.org::*Org 链接]]
#+end_src

→

#+begin_src org
  #+HEADER: :transclude [[file:~/notes/emacs.org::*Org 链接]]
  #+begin_quote
  ,* Org 链接
  Org 链接的正文……

  ,** 子标题
  子标题的正文。
  #+end_quote
#+end_src

* 安装

要求：Emacs 27.1 + Org 9.3。**本包只依赖 Org 自身**，不需要、也不会加载
org-transclusion 或 org-transclusion-blocks。

#+begin_src emacs-lisp
  (use-package org-quote-link
    :ensure nil                     ; 本包不在 ELPA 上
    :load-path "/path/to/org-quote-link"
    :bind (("C-c q" . org-quote-link)
           :map org-mode-map
           ("C-c Q" . org-quote-link-refresh)))
#+end_src

不用 =use-package= 的话：

#+begin_src emacs-lisp
  (add-to-list 'load-path "/path/to/org-quote-link")
  (require 'org-quote-link)
#+end_src

* 使用

** 推荐入口

只绑定一个命令 =M-x org-quote-link= 就够了。它会根据光标位置自动分派：

| 光标位置                                       | 动作                       |
|------------------------------------------------+----------------------------|
| 带 =#+HEADER: :transclude [[LINK]]= 的块内部     | 刷新这个块                 |
| 单行 Org 链接上                                 | 把链接转换成引用块         |
| 其它位置                                       | 报 =user-error=，不改 buffer |

分派时优先看“是否在块里”，再看“是否在链接上”；因此块里的链接也会触发刷新。

如果想跳过判断、强制做某个动作，仍然可以直接调用下面两个显式命令。

** 转换链接（显式命令）

光标放在链接上，执行：

#+begin_src emacs-lisp
  M-x org-quote-link-at-point
#+end_src

几条规则：

- 链接必须单独占一行（行首可以有空白）；行内链接会报错，不改动 buffer。
- 链接类型以 =org-store-link= 能生成的为准：=file:= 链接（heading、=#custom-id=、
  target、=#+name:=、行/区域文字搜索、整个文件）、=id:=，以及注册了 =:store=
  的第三方类型（如 denote）。手动输入的 fringe 链接、=[[#custom-id]]=、
  =https:= 等默认拒绝。
- heading 默认连标题行一起引用（=org-quote-link-include-headline= 可关），
  Org 来源会做逗号转义，避免 =*= / =#+= 行破坏 quote-block。

完整链接类型表与行为细节见 [[file:docs/technical-details.org][技术细节]]。

** 刷新（显式命令）

引用块是快照。要重新抓取，把光标放在块里，执行：

#+begin_src emacs-lisp
  M-x org-quote-link-refresh
#+end_src

（=M-x org-quote-link= 在块里执行时也会做同样的事。）

它只依赖 Org，读取块里的 =#+HEADER: :transclude [[LINK]]= 行重新解析和替换
正文；光标在 header / begin / 正文 / end 行都可以。

** 常用设置

| 变量                                   | 默认值   | 作用                          |
|----------------------------------------+----------+-------------------------------|
| =org-quote-link-block-type=            | ="quote"= | 生成的块类型（quote/example…）|
| =org-quote-link-include-headline=      | =t=       | heading 是否包含标题行        |
| =org-quote-link-escape-non-org-syntax= | =nil=     | 是否也转义非 Org 文件内容     |
| =org-quote-link-link-handlers=         | denote   | 扩展/自定义链接类型           |

其它变量和扩展接口（handler 协议、denote、自定义类型示例）见
[[file:docs/technical-details.org][技术细节]]。

* 与 org-transclusion-blocks 的差异对比

两者都会生成 =#+HEADER: :transclude [[LINK]]= + quote-block；但定位不同：
=org-quote-link= 是一个**零依赖的小工具**，只负责“把光标处的链接变成引用块并
保存一份快照”；=org-transclusion-blocks= 是一套**组件化 transclusion 框架**，
负责在自己的 header 语法下抓取、刷新、调整范围和加 overlay。

| 维度             | org-quote-link                                   | org-transclusion-blocks                          |
|------------------+--------------------------------------------------+--------------------------------------------------|
| 依赖             | 只依赖 Org（Emacs 27.1 + Org 9.3）               | Emacs 29.1 + Org 9.7 + org-transclusion 1.4      |
| 定位             | 一条命令：链接 → 静态引用块快照                  | 框架：手写 header/block，再用命令抓取内容        |
| 输入方式         | 光标处的现有 org-link                            | 已有的 =#+HEADER: :transclude …= + block         |
| 链接范围         | 刻意收窄到 =org-store-link= 能生成的类型         | org-transclusion 的 fetchers 能处理的所有类型    |
| 内容粒度         | heading（含标题行）/ 元素 / 整个文件             | 还有 =:lines=、=:thing-at-point=、=:only-contents=、=:level=、=:expand-links= 等 |
| block 类型       | quote（可配置 example/verse）                    | src/quote/example/special/export/comment…，src 走 Babel |
| 刷新命令         | 自带的 =org-quote-link-refresh=（只依赖 Org）    | =org-transclusion-blocks-add= / transient 菜单   |
| 转义             | Org 来源转义、非 Org 原样，可配置；非默认决定会记录在块里 | =org-transclusion-blocks-escape-org-sources= + =:transclude-escape-org= |
| 元数据/overlay   | 不添加，输出就是纯文本                           | 添加 text properties、overlay、刷新时间等        |
| 自引用           | 拒绝 heading / 元素 / 整个当前文件的自我嵌套     | 有自己的检查逻辑                                 |

怎么选：

- 只是想让“链接 → 引用块”一步完成、保持零依赖、用自带命令刷新：用
  =org-quote-link=；
- 需要 =:lines= / =:thing-at-point= / 组件类型 / 菜单和 overlay：用
  =org-transclusion-blocks=；
- 两者可以共存：=org-quote-link= 生成的格式与 blocks 的 header 约定相同，
  装了 blocks 时它的 add 命令通常也能识别（**可选互操作，不是本包的依赖**）。
  相关差异和注意事项见 [[file:docs/technical-details.org][技术细节]]。
